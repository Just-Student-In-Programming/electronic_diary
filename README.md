📚 Электронный дневник

Электронный дневник — это десктопное приложение на Python, созданное для автоматизации учета успеваемости студентов и школьников. Проект написан с использованием принципов объектно-ориентированного программирования (ООП) и современной библиотеки для создания графического интерфейса.
✨ Ключевые возможности

    🔐 Ролевая система доступа:

        Учитель: может добавлять/удалять учеников, выставлять и удалять оценки, просматривать успеваемость всей школы.

        Ученик: имеет доступ только к своему личному дневнику и рейтингу своей группы (чужие оценки скрыты в целях конфиденциальности).

    🔍 Живой поиск: Мгновенная фильтрация списка учеников по имени или фамилии.

    🧮 Умный калькулятор оценок: Уникальная фича для учеников, которая рассчитывает, сколько «пятерок» нужно получить, чтобы выйти на желаемый средний балл.

    🏆 Геймификация: Рейтинг группы с медалями (🥇, 🥈, 🥉) для топ-3 учеников по успеваемости.

    🚀 Оптимизация (Кэширование): Средний балл рассчитывается только при изменении оценок, а не при каждом рендеринге списка, что обеспечивает плавную работу интерфейса.

    💾 Сохранение данных: Все данные автоматически сохраняются в локальный файл data.json.

🛠️ Технологический стек

    Язык: Python 3.13

    GUI (Интерфейс): CustomTkinter (современный темный дизайн)

    Хранение данных: JSON

    Сборка приложения: PyInstaller (компиляция в .exe)

    Архитектура: Паттерн MVC (Model-View-Controller) в упрощенном виде, разделение логики и интерфейса.

📂 Структура проекта

    gui_main.py — графический интерфейс приложения (View).

    main.py — консольная версия приложения (резервная).

    student.py, group_students.py, teacher.py — бизнес-логика и модели данных (Model).

    constants.py — централизованный конфиг (цвета, лимиты, список предметов).

    utils.py — вспомогательные функции (безопасный ввод, округление).

    data.json — локальная база данных.

🚀 Как запустить
Вариант 1: Готовое приложение (Windows)

    Скачайте файл ElectronDiary.exe из раздела Releases (или из папки dist, если она доступна).

    Запустите .exe двойным кликом.

Вариант 2: Запуск из исходного кода

    Клонируйте репозиторий:
    bash

    git clone https://github.com/Just-Student-In-Programming/electronic_diary.git

    Установите зависимости:
    bash

    pip install -r requirements.txt

    Запустите приложение:
    bash

    python gui_main.py
